# База знаний

Структурированные md-файлы о проектах, областях ответственности и справочных материалах — для быстрого чтения человеком и загрузки контекста в ИИ-агентов. Просматривается и редактируется через [repodocs](https://github.com/smogick/repodocs).

```
├── {{docsDir}}/
│   ├── projects/    — проекты и продукты с конкретной целью/результатом
│   ├── areas/       — постоянные зоны ответственности (команда, поддержка, инфраструктура)
│   ├── resources/   — справочные материалы (домены, глоссарий, сервера)
│   ├── archive/     — завершённые/неактуальные проекты (не удаляются, а переносятся сюда)
│   ├── templates/   — шаблоны для новых карточек
│   ├── schema/      — описание frontmatter и чек-лист качества
│   ├── local/       — секреты и приватные данные, НЕ попадает в git
│   └── trash/       — корзина UI, 30 дней
├── CLAUDE.md        — инструкции для ИИ-агентов
└── INDEX.md         — сводная таблица всех карточек (генерируется)
```

Карточка — папка внутри `{{docsDir}}/<раздел>/` с `README.md` (YAML frontmatter, см. [{{docsDir}}/schema/frontmatter.md]({{docsDir}}/schema/frontmatter.md)) и любыми дополнительными `.md`, либо одиночный `.md` для простых ресурсов.

Новая карточка:

```bash
mkdir -p {{docsDir}}/projects/<slug>
cp {{docsDir}}/templates/project.md {{docsDir}}/projects/<slug>/README.md
```

Секреты — только в `{{docsDir}}/local/`, в остальных файлах ссылка по имени.
