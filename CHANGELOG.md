# Changelog

## Unreleased

- Визуальный редактор (четвёртый режим панели, иконка карандаша) на базе Milkdown Crepe: слэш-меню блоков, drag-handle, всплывающая панель форматирования, таблицы с контролами строк/столбцов, правка ссылок во всплывашке, блоки кода с выбором языка. Frontmatter остаётся в панели метаданных, сохранение идёт через тот же путь, что и из source-режима.

## 0.0.2 — 2026-09-16

- Создание новой карточки из UI (кнопка «+» в шапке): раздел, название, slug с автотранслитерацией, summary. README.md собирается из шаблона `templates/<type>.md`.
- `npm run init` — разворачивает scaffold (CLAUDE.md, схема, шаблоны, папки) в новую базу заметок.
- `npm run claude-global` — секция со ссылкой на INDEX.md и списком проектов в `~/.claude/CLAUDE.md`.
- Лицензия MIT.

## 0.0.1 — 2026-09-09

Первый релиз. UI вынесен из репозитория с заметками в отдельный проект.

- Список карточек с фильтрами по статусу, стеку и тегам, полнотекстовый поиск.
- Дерево файлов карточки: создание, перемещение (в том числе drag & drop), папки.
- Просмотр и редактирование markdown, рендер mermaid-диаграмм, форма для frontmatter.
- Мягкое удаление с 30-дневной корзиной и восстановлением.
- Автогенерация `INDEX.md` при сохранении README, отметка карточек с устаревшим `updated`.
- Расположение заметок задаётся в `config.json` (`root`, `docsDir`, `port`).
