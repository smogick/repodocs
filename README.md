# repodocs

Локальный веб-интерфейс для markdown-базы знаний: список карточек с фильтрами по статусу/стеку/тегам, полнотекстовый поиск, дерево файлов, просмотр и редактирование markdown (mermaid-диаграммы рендерятся), редактирование frontmatter через форму, мягкое удаление с 30-дневной корзиной, автогенерация `INDEX.md`.

Сами заметки в этом репозитории не лежат — UI открывает любую папку, указанную в `config.json`.

## Запуск

```bash
npm install
cp config.example.json config.json   # укажи путь к заметкам в "root"
npm start
```

UI поднимается на `http://localhost:4173`.

## config.json

```json
{
  "root": "../repodocs",
  "docsDir": "docs",
  "port": 4173
}
```

| Поле | Обязательное | Описание |
|---|---|---|
| `root` | да | Путь к репозиторию с заметками (абсолютный или относительно `config.json`). В корне генерируется `INDEX.md`. |
| `docsDir` | нет | Папка с контентом внутри `root`, по умолчанию `docs`. |
| `port` | нет | Порт, по умолчанию `4173`. Переменная окружения `PORT` имеет приоритет. |

Путь к самому конфигу можно переопределить переменной `REPODOCS_CONFIG`. `config.json` в `.gitignore` — у каждого свой.

## Ожидаемая структура заметок

```
<root>/
├── INDEX.md              — генерируется (npm run build-index или автоматически при сохранении README в UI)
└── <docsDir>/
    ├── projects/         — карточки: папка с README.md (+ любые .md и подпапки) или одиночный .md
    ├── areas/
    ├── resources/
    ├── archive/
    └── trash/            — корзина UI, создаётся сама
```

Карточка — это `README.md` с YAML frontmatter (`title`, `type`, `status`, `stack`, `tags`, `summary`, `updated`, …) либо одиночный `.md` с тем же frontmatter прямо в корневой папке. UI редактирует только файлы внутри `<docsDir>` и `INDEX.md`.

## Скрипты

- `npm start` — запустить сервер.
- `npm run build-index` — пересобрать `INDEX.md` без запуска UI.
